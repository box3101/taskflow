# 전일 장 요약 입력

`flow-sonnet-v6-previous-day`부터 신규 수급 AI 판단에 당일 기록과 전일 요약을 함께 전달한다. 기존 AI 요청의 입력만 늘리며 별도 모델 호출·기존 판단 재생성은 하지 않는다. 추가 입력 토큰 비용은 발생할 수 있다.

- 분석일보다 앞선 가장 최근 저장일을 조회한다. 주말·휴일을 포함한 달력상 간격과 원래 날짜를 표시하며, 중간 거래일 기록이 없을 수 있으므로 직전 거래일이라고 확정하지 않는다.
- 정규장 09:00–15:30 관측만 사용한다. 미래 날짜·분석 시각 이후 관측은 제외한다.
- 최종 누적 현물·선물·외국인/전체 비차익, 코스피 최종 관측 등락률과 관측 고저, 마감 30분 변화, 수집 공백을 요약한다.
- 15:30 관측이 없거나 30분 비교 자료의 공백/단위 변경이 있으면 마감 30분 변화는 null이다. 소스 오류는 0으로 바꾸지 않는다.
- 최종 관측값은 거래소 확정 수급·종가가 아니다. 관측 고저도 공식 고저가 아니다.
- 오늘 가격·수급을 우선하며 전일 누적과 당일 누적을 차감/합산하지 않도록 지시한다. 오늘 필수 관측 부족을 전일 자료로 대체하지 않는다.
- `payload.record.previousDayContext`에 실제 전달된 요약이 보존되며, 분석 버전으로 적용 전후를 구분할 수 있다. 과거 판단은 변경하지 않는다.

2026-09-29 실저장 380건으로 다음 거래일 입력을 검증했다. 최종 관측은 15:30:02, 공백 8개이며, 마지막 30분은 수집 공백으로 null이다. 압축 요약은 약 1,328자였다. 이 확인 과정에서 유료 AI는 호출하지 않았다.
