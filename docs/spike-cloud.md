# Railway 급등 탐지기

Railway 앱 프로세스에서 매 10초 수집. `SPIKE_CLOUD_ENABLED=false`로 중지 가능. Railway 외 로컬은 명시적 true 설정 없이는 실행하지 않음.

- 평일 08:55 준비, 09:00~15:30 탐지, 15:32까지 종가 관측. KIS 거래일 확인 실패/휴장은 수집하지 않음.
- 서버의 기존 KIS 키는 거래일 확인에 사용. 시세는 Naver REST, 원 단위 통합 누적 거래대금 사용. 로컬 KIS WS 가속 없이 10초 해상도이므로 로컬 알림과 시각·신호가 다를 수 있음.
- 122개 관찰 종목과 11개 테마를 날짜별 고정. chg20 시작 시 조회, 실패한 종목은 추세 분류 불명으로 보존.
- 3분 가격 이력, 09~10시 1.2%/이후 1.5%, 당일 상승률 <= min(테마 중앙값,5%), 10분 쿨다운. 원본처럼 초기 이력이 2개면 비교 시작. 30초 초과 수집 공백은 이력 초기화.
- DB 트랜잭션 advisory lock으로 다중 서버 중복 수집 방지. 날짜별 이력/쿨다운과 원시 시세 스냅샷·알림·순위를 PostgreSQL에 저장. 재배포 후 복구.
- 원본 과거 알림은 읽기 전용 아카이브 포함. 계좌/주문/텔레그램 데이터는 클라우드에 연결하지 않음.
- 새 신호 순위만 계산. 시세 누락/지연이 있는 테마는 판단 불가. REST 거래대금 시간과 WS 가격 시간 혼용 없음.
- 이후 가격 관측으로 원본 표의 수익률을 채점. 장중 경로 공백이 있으면 경로 의존 청산 성적은 null. 종가는 실제 15:30 이후 시각의 시세가 확보된 경우만 채점. 종가 누락은 미채점 유지.
- 조회 소유자는 AVERAGE_SPIKE_OWNER_ID 또는 기존 FLOW_AUTO_USER_ID. 데이터 수집과 자동 주문은 별개이며 이 서비스는 주문·메시지 발송 없음.
- Railway 자동 수면 비활성화. PC/브라우저 불필요. Railway 및 원본 시세 서비스 장애가 있으면 수집 공백 발생 가능.

배포 시 기존 postinstall의 prisma migrate deploy가 spike_cloud_* 테이블 생성. 일별 pool/20일 변화량/마지막 수집시각은 spike_cloud_days, 원시 시세는 spike_cloud_snapshots, 알림과 판정은 spike_cloud_signals에 보존.
