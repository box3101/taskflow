# 외국인 수급 관측

주식 화면은 ispark-ui의 탭, 버튼, 날짜 선택, 표, 차트, 파일 업로드를 사용합니다.
서버가 정규장 거래일에 1분마다 외국인 현물 순매수, KOSPI200 선물 순매수 계약,
코스피 외국인 비차익 순매수와 코스피 지수를 조회합니다. 브라우저를 닫아도 서버가 실행 중이면 수집합니다.

## 실행 설정

- `backend/.env`에 실전 `KIS_APP_KEY`, `KIS_APP_SECRET`을 설정하고 서버를 재시작합니다.
- `.env`는 Git에서 제외됩니다. 프런트엔드 환경변수에 키를 넣지 않습니다.
- 배포 서버에는 해당 서버의 환경변수로 별도 설정해야 합니다.
- `backend`에서 `npx prisma migrate deploy`로 수급 기록 및 PDF 저장 테이블을 생성합니다.
- 금액 단위는 API 문서 및 HTS와 대조한 뒤 `KIS_CASH_AMOUNT_UNIT`,
  `KIS_PROGRAM_AMOUNT_UNIT`에 `won`, `million`, `eok` 중 하나를 지정합니다.
  미설정 상태에서는 환산하지 않고 `API 원단위`로 표시합니다.

## 해석과 복기

5·15·30분 전 관측 대비 변화로 규칙 기반 가설을 생성합니다. 외국인 집단 전체의
집계치이므로 개별 투자자의 의도를 확인한 결과가 아닙니다. 현물과 비차익은 겹칠 수 있어 합산하지 않습니다.
관측이 부족하거나 수집이 끊긴 구간은 판단을 보류합니다. 원천 데이터 시각이 제공되지 않으면
수신 시각과 구분하며, 1분 조회를 거래소 실시간 틱 데이터로 표시하지 않습니다.

가설은 생성 당시의 데이터와 함께 보관합니다. 이후 15·30분의 지수 변화로 복기하며
관망·중립 가설은 방향 적중률에 포함하지 않습니다. 과거 시세를 현재 관측으로 채우지 않습니다.

## AI 판단 · RAG · 성능 검증

`AI 판단·검증` 탭에서 PDF 검색 준비 → 예측 구간(15·30분) 선택 → 판단 생성을 실행합니다.
현재 버전은 사용자가 실행하는 분석 파이프라인입니다. 자동 주문이나 무인 AI 반복 실행은 하지 않습니다.
수급 수집과 결과 관측은 기존 1분 수집기를 사용하고, 탭을 열어 두면 결과를 갱신합니다.

- 기본 판단은 `ANTHROPIC_API_KEY`와 `FLOW_BASIC_MODEL`(기본 `claude-sonnet-5`)을 사용합니다.
  기존 `FLOW_AI_MODEL`은 수급 판단에 사용하지 않습니다. 기존 뉴스 분석용 Gemini 설정은 별개입니다.
- `20260924100000_add_flow_agent` 마이그레이션 적용 후 서버를 다시 시작해야 합니다.
- PDF 원문은 서버에서 추출합니다. 최대 10MB·100페이지·35만 글자, 문단 최대 400개입니다.
  암호화/손상/스캔 PDF는 오류 상태를 표시하며, 스캔 PDF의 OCR은 지원하지 않습니다.
- 페이지별 문단을 저장하고 한국어 bigram BM25 검색으로 관련 문단 최대 6개를 모델에 전달합니다.
  임베딩 서비스 없이 동작하는 어휘 검색 RAG이며, 동의어/의미 검색 품질에는 한계가 있습니다.
- 인증된 사용자 소유의 검색 준비 완료 PDF 중 관측 당시 업로드되어 있었고 자료 기준일이
  관측일 이전 또는 당일인 최근 100개만 검색합니다. PDF에 적힌 발행일을 자동 검증하지 않습니다.
  나중에 첨부한 과거 날짜 PDF는 과거 관측의 근거로 소급 사용하지 않습니다. 메모는 검색하지 않습니다.
- 기본 판단 실행 시 관측값, 코드로 계산한 변화량, 단위, 검색된 PDF 발췌문을 Claude Sonnet에 전송합니다.
  원문 전체나 다른 사용자 자료는 전송하지 않습니다. 문서 내부 지시는 모델 지시로 취급하지 않습니다.
- 상승·하락·중립·보류, 근거, 반대 신호, 판단 변경 조건, 인용 ID를 형식 검증합니다.
  제공하지 않은 인용은 거절하고, 필수 관측이 누락되면 방향을 보류로 강제합니다.
- 최초 판단, 입력 수급, 발췌문, 모델/프롬프트 버전, 생성 시각을 저장합니다.
  동일 사용자·관측·예측 구간·PDF 사용 여부는 재생성하지 않습니다. 최근 24시간 최대 80건입니다.
  PDF를 삭제해도 이미 생성된 판단의 근거 발췌문은 감사 기록으로 보존됩니다.

### 평가 정의

정규장 중 90초 이내의 관측으로 요청하고 관측 후 180초 이내에 생성된 판단만 실시간으로
분류합니다. 과거/지연 생성은 `replay`로 저장하고 실시간 성적에서 제외합니다.
LLM의 사전 학습 지식 때문에 과거 재분석을 엄밀한 당시 예측 백테스트로 간주하지 않습니다.

실시간 평가는 **AI 생성 이후 90초 이내의 첫 정상 코스피 관측**을 시작 가격으로 사용합니다.
그 시작 시각에서 15·30분 이후 첫 90초 이내 정상 관측과 비교합니다. 응답 대기 중에 이미
발생한 가격 변화를 성적에 넣지 않습니다. 당일 장 종료 이후 목표, 누락, 미도래는 별도로 표시합니다.
중립/보류는 적중률 분모에서 제외하고 판단 비율(방향 판단 수 / 결과 관측 수)을 함께 표시합니다.
변화율이 정확히 0이면 상승/하락 판단 모두 불일치입니다. 규칙 비교는 AI와 규칙이 모두 방향을
제시한 같은 표본, 같은 시작·종료 가격을 사용합니다. 성적은 선택한 거래일 기준입니다.

겹친 구간은 독립 표본이 아닙니다. 표시된 적중률은 수익성·통계적 유의성을 입증하지 않으며,
확률 보정, 거래 비용, 체결 시뮬레이션, 무인 실행, 임베딩 검색은 이 버전에 포함하지 않습니다.
평가 결과는 불변 원본 관측과 저장된 판단에서 조회 시 계산합니다.

## 같은 시점에서 PDF 효과 비교

- 화면의 비교 실행은 `POST /market-flow/agent/compare`로 동일 모델·관측·구간·프롬프트의
  수급 전용(`flow`)과 PDF 포함(`rag`) 응답을 병렬 생성합니다. 1회 실행은 한도 2건을 사용합니다.
- 두 응답이 모두 검증되어야 하나의 트랜잭션으로 저장합니다. 입력과 검색 자료는 요청 시작 시 고정하고,
  평가 시작 시각은 두 생성이 모두 완료된 시각으로 통일합니다. 각 응답 완료 시각도 별도 보존합니다.
- 실시간 완성 쌍만 비교하며 과거 분석, 모델/버전이 다른 쌍, PDF 발췌문이 없는 쌍은 효과 평가에서 제외합니다.
  규칙/수급 AI/PDF AI의 적중률, 판단 비율, 보류·중립 비율, 방향 평가 건수를 표시합니다.
  세 방식 모두 방향을 낸 공통 표본의 적중률도 별도 표시합니다. 모델의 무작위성은 여전히 남습니다.
- 수급을 주된 근거로, PDF는 배경·반대 근거로 사용합니다. 근거 부족/충돌 시 보류하며,
  사후 설명 능력을 미래 예측 능력으로 간주하지 않습니다. 기존 단일 판단은 덮어쓰지 않습니다.

## 심층 검토와 장 마감 복기

- `20260924110000_add_flow_expert_review`, `20260924120000_add_flow_comparison`까지
  `prisma migrate deploy`와 `prisma generate`를 실행하고 서버를 재시작합니다.
- 기본 선택은 Claude Sonnet(`FLOW_BASIC_MODEL=claude-sonnet-5`, `ANTHROPIC_API_KEY`)이며 기본 판단과 같은 모델 설정을 사용합니다.
  기존 `FLOW_OPUS_MODEL` 설정은 더 이상 사용하지 않습니다.
  GPT Astra(`FLOW_ASTRA_MODEL=gpt-6-astra`, `OPENAI_API_KEY`)도 선택할 수 있습니다.
  키가 없는 제공사는 설정 필요로 표시하며 다른 제공사로 몰래 전환하지 않습니다.
- `GET/POST /market-flow/expert`: 사용자별 심층 검토와 복기를 별도 테이블에 보존합니다.
  자동 실행 없이 버튼으로 요청합니다. 현물/선물/비차익/지수 변화의 부호 충돌은 화면에 검토 신호로 표시합니다.
- 심층 검토는 선택 관측까지의 자료만 사용합니다. 마감 복기는 해당 날짜 15:40 KST 이후 가능하며,
  실행 시점까지 업로드된 기준일 이하 PDF도 사용합니다. 이 자료로 과거 예측 성적을 수정하지 않습니다.
- 전체 관측 건수와 범위, 15분 구간별 마지막 관측 및 처음/마지막 관측, 기본 판단,
  관련 문단 최대 12개를 전달합니다. 누락 구간을 생성하지 않습니다. 복기는 예측 적중률에서 완전히 제외합니다.
- 하루 같은 마감 복기/제공사 또는 같은 관측 심층 검토/제공사는 재생성하지 않습니다.
  최근 24시간 심층 분석 최대 20건. API 타임아웃 110초, 실패 응답은 저장하지 않습니다.
- Sonnet은 Anthropic Messages의 JSON 출력, Astra는 OpenAI Responses의 엄격한 JSON 출력과
  `store:false`를 사용합니다. 모델 응답의 인용·필수 필드 검증 후 저장합니다.

## 확인

### 월간 대시보드

- 주식 탭의 기본 화면은 `UiCalendarMonth`를 사용하는 월간 대시보드입니다.
- `GET /market-flow/calendar?month=YYYY-MM`은 수급 관측 건수와 사용자 소유의 PDF·기본 AI·심층 검토·마감 복기 건수를 날짜별로 집계합니다. PDF 원문이나 전체 월간 수급 payload는 전송하지 않습니다.
- 날짜 선택은 달력의 일별 요약을 갱신하며, 요약의 버튼으로 수급/AI/PDF/장전 비교 화면에 진입합니다. 선택 날짜와 화면은 URL의 `date`, `view`에 보존됩니다.
- 수급 기록일은 하루 전체 수집 완료를 뜻하지 않습니다. 빈 날을 휴장으로 추정하지 않습니다. 기본 AI 건수는 수급 전용과 PDF 포함 판단을 각각 세며, 적중률은 AI 판단·검증 상세 화면에서 확인합니다.

`backend`: `npx vitest run src/services/flowAnalysis.test.ts src/services/kisFlow.test.ts src/routes/marketFlow.test.ts src/services/flowAgent.test.ts src/routes/flowAgent.test.ts --maxWorkers=1`

`frontend`: `npm run build`

실제 연결 확인은 조회 API만 사용합니다. 테스트용 시세는 운영 관측 테이블에 저장하지 않습니다.
