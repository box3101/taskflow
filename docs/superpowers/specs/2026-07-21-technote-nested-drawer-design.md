# 기술노트 단계형 뷰어 (중첩 Drawer 내비게이션) 설계 스펙

- 작성일: 2026-07-21
- 대상 프로젝트: TaskFlow
- 대상 화면: 기술노트(TechNote) 상세 보기

## 1. 배경 / 목표

기술노트 상세는 현재 `TechNoteDrawer.vue`가 본문(마크다운)을 `UiMarkdownEditor`(읽기전용)로 **한 덩어리로 통째** 렌더한다. 단계별 설계 노트처럼 본문이 길어지면 한 화면에서 계속 스크롤해야 해서 "지도"가 없고 나중에 다시 보기 힘들다.

목표: 긴 노트를 **목차 → 단계 클릭 → 상세가 겹쳐 슬라이드**되는 중첩 Drawer로 보여준다. 데이터 구조 변경 없이, 본문 마크다운을 `##` 제목 기준으로 잘라 구성한다.

## 2. 확정된 결정

| 항목 | 결정 |
|------|------|
| 내비게이션 패턴 | **중첩 Drawer(B)** — 목차 drawer 위에 상세 drawer가 겹쳐 슬라이드 |
| 상세 여는 방식 | **겹쳐 슬라이드**(새 drawer 스택), `‹ 목차로`/배경 탭/ESC로 닫힘 |
| 섹션 분리 | 본문을 **`## ` 제목 기준으로 분할**(프론트 렌더 시). 데이터·저장 방식 불변 |
| 적용 조건 | **자동** — `##` 섹션이 **2개 이상**이면 목차형, 아니면 기존처럼 통짜 렌더 |
| 목차 구성 | `#` 제목 + 첫 `##` 이전 본문(진행현황 등 intro, 인라인) + `##` 섹션 제목 리스트 |
| 모바일 | 상세는 전체폭 오버레이 |
| 편집 모드 | 기존 그대로(통짜 마크다운 편집). 본 기능은 **보기 모드에만** 적용 |

## 3. 아키텍처

**프론트엔드 전용.** 백엔드·스키마·API 변경 없음. 노트 본문은 지금처럼 마크다운 한 문자열로 저장·조회한다.

```
note.content (마크다운)
   │  parseSections()  ── "## " 기준 분할
   ▼
{ intro: "# 제목 + 첫 ## 이전 본문", sections: [{ title, body }...] }
   │
   ├─ sections.length >= 2 → 목차형(중첩 Drawer)
   └─ 아니면            → 기존 통짜 렌더(현행 유지)
```

## 4. 컴포넌트 / 동작

### 4.1 섹션 파서 — `parseNoteSections(content)` (신규 유틸)
- 입력: 노트 본문 마크다운.
- 출력: `{ intro: string, sections: { title: string, body: string }[] }`
  - `intro` = 첫 `## ` 이전 전체(‑ `#` 제목, 리드 문단, 진행현황 등).
  - 각 `## 제목`부터 다음 `##` 직전까지가 한 `section`. `title`은 `## ` 뒤 텍스트, `body`는 그 섹션 마크다운(제목 포함 또는 제외 — 렌더 일관성 위해 제목 제외하고 별도 표시).
- 코드블록 안의 `##`(예: 주석)은 섹션으로 오인하지 않도록 ``` 펜스 안은 무시.

### 4.2 목차(마스터) — `TechNoteDrawer.vue` 보기 모드 확장
- `sections.length < 2` → 지금과 동일(통짜 `UiMarkdownEditor`).
- `>= 2` → 목차 렌더:
  - 상단: 카테고리·태그(현행) + `intro`를 `UiMarkdownEditor`(읽기전용)로 렌더(진행현황 인라인 표시됨).
  - 그 아래: **단계 리스트** — 각 `section.title`을 행으로, 우측 `›`. 클릭 → 상세 열기.

### 4.3 상세(디테일) — 중첩 Drawer
- 단계 클릭 시 `activeSection` 지정 + 상세 drawer 오픈.
- 상세 drawer: 상단 `‹ 목차로`(뒤로) + `section.title`(헤더) + `section.body`를 `UiMarkdownEditor`(읽기전용) 렌더.
- 닫기: 뒤로 버튼 / 배경 탭 / ESC → 목차로 복귀(목차 스크롤 위치 유지).
- **구현 주의:** `ispark-ui`의 `UiDrawer`가 **중첩(스택)** 을 지원하는지 확인 필요.
  - 지원 → 두 번째 `UiDrawer`를 더 높은 z-index로 겹쳐 오픈.
  - 미지원 → 첫 drawer 내부에 **자체 슬라이드 오버레이 패널**로 상세 구현(폴백). 동작·외형은 동일.

### 4.4 모바일
- 상세 drawer는 전체폭 오버레이. 뒤로/배경 탭으로 닫힘.

## 5. 엣지 케이스

- `##` 섹션 1개 이하 → 기존 통짜 렌더(회귀 없음).
- 코드블록/인용 안의 `##` → 섹션으로 오인 금지(펜스 인식).
- 섹션 본문이 비어도(제목만) 상세 열림은 정상.
- 편집 모드 진입/저장 → 통짜 마크다운 그대로(파싱은 보기 모드 전용).
- 아주 긴 단일 섹션 → 상세 drawer 내부 스크롤.

## 6. 범위 밖 (이번 버전 제외)

- 섹션별 개별 편집(지금은 통짜 편집 유지).
- `###` 하위 목차/2단계 중첩(1단계 목차→상세까지만).
- 목차 자동 앵커·딥링크(URL로 특정 섹션 열기).
- 데이터 모델화(섹션을 별도 레코드로 저장) — 불필요(YAGNI).

## 7. 테스트 관점

- `parseNoteSections`: `##` 분할, intro 추출, 코드펜스 내 `##` 무시.
- 보기 모드: 섹션 2개 미만이면 기존 렌더, 이상이면 목차 렌더.
- 상세 열기/뒤로/배경 탭 동작, 목차 스크롤 유지.
- 모바일 전체폭.

## 8. 구현 순서 (개요 — 상세는 implementation plan에서)

1. `parseNoteSections` 유틸 + 단위 테스트.
2. `TechNoteDrawer.vue` 보기 모드에 목차 분기(2개 이상 시).
3. 상세 중첩 Drawer(또는 폴백 오버레이) + 뒤로/닫기.
4. 모바일·스크롤 유지 마감.
