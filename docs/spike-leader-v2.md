# 세부 테마 상위 3위 관찰

- 원래 122종목과 점화 탐지 조건을 보존한다. `spike-leader-pool.json`은 별도 연구용 분류이며 경제적 사업 분류 가설이지 검증된 주가 동행 그룹이 아니다.
- 새 연구 분류는 날짜별 최초 적용 때 고정된다. 종목 추가 없이 반도체 제조/장비/소재/후공정/설계, PCB, 전력기기/전선/원전, 자동차/로봇 등을 분리한다.
- 누적 거래대금 경쟁 순위 3위 이내를 후보(pass)로 저장한다. 공동 순위로 3개를 초과할 수 있다. 그룹이 2~3종목이면 모두 통과하며 1종목이면 판단 불가다.
- 5분 거래대금 = 현재 누적 − 5분 전 누적. 직전 5분 대비 배수 = (현재−5분 전)/(5분 전−10분 전). 분모 0이면 null.
- 5분 가격 강도 = 종목 5분 수익률 − 테마 모든 구성 종목 5분 수익률 중앙값(%p). 자기 자신도 중앙값에 포함한다.
- 기준 시각 이전 20초 이내 표본만 사용한다. 미래 표본을 사용하지 않는다. 30초 넘는 공백, 날짜 변경, 거래대금 감소는 관측 이력을 초기화한다. 가격 강도는 테마 전체 연속 관측이 있어야 한다.
- 5분 지표는 비교 정보이며 추가 통과 조건이나 자동 매수 지시가 아니다. 신호 시점에 version=leader-v2와 동결된 근거를 저장한다. 기존 v1 신호를 다시 판정하지 않으며 성적도 섞지 않는다.
- 후보판은 최신 저장 관측 시각 기준이며 과거 알림 필터와 독립적이다. 최초 5분/10분은 지표 수집 대기다. 당일 이력은 DB에 보존되므로 재시작해도 이어진다.
- 거래대금과 가격 수집 출처 및 원래 탐지기 한계는 spike-cloud.md 참조.

검증: 순위 경계, 누락, 지표 계산, 수집 공백, 누적값 초기화, 122종목 보존 테스트 및 양쪽 타입 검사·프론트 빌드.
