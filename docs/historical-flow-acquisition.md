# 2026-09-22 과거 장중 수급 확보 현황

확인일: 2026-09-24. 현재 과거 현물·선물·비차익 데이터 취득에 성공한 상태가 아니다.

## 로컬 실행 전제

일반 설치 경로, Windows 프로그램 등록 목록, 실행 프로세스에서 eFriend Expert와
예스트레이더를 찾지 못했다. Expert 공식 CLSID
`{08E39D09-206D-43D1-AC78-D1AE3635A4E9}`도 HKCR, WOW6432Node 및
사용자별 COM 등록 경로에 없었다. 비표준 설치 경로 존재 가능성은 남아 있다.

기존 KIS Developers REST 앱키는 Expert 로그인 대체 수단이 아니다.
Expert는 이용 신청, Windows 모듈 설치, HTS ID 로그인이 필요하다.
사용자 인증·약관 동의는 사용자가 진행하며 비밀번호를 코드나 대화에 넣지 않는다.

## Expert 첫 조회 계획

최신 스펙은 로그인 후 트레이 메뉴의 Expert Viewer에서 재확인한다.
공식 매뉴얼 243쪽의 조회 TR은 `PPG04600100` (프로그램매매 종합현황/시간).

- 입력 0: 시장 구분, 문서 예제 `K`.
- 입력 1: 입력 날짜1, 10자리 문서 예제 `0020151015`.
  2026-09-22에 해당하는 후보 값은 `0020260922`이나 Viewer의 최신 형식 확인 전 확정하지 않는다.
- 출력: 영업 시간, 차익 및 비차익 합계 매수·매도·순매수 거래대금.
- 범위: **시장 전체 비차익**. 외국인 비차익 필드로 저장하지 않는다.
- 문서에 날짜 입력이 있다는 사실만으로 과거 날짜 지원·보관기간을 확정하지 않는다.

비교용으로 두 날짜를 각각 조회해 응답이 실제로 달라지는지 확인한다. 응답이 시각만 제공한다면
날짜 입력이 무시되어 당일 값을 반환하는지 반드시 점검한다. 당일/목표일 일별 합계와
HTS 날짜 표시를 대조해 날짜를 검증하기 전에는 22일 데이터로 대시보드에 넣지 않는다.
단위, 누적/증분, 전체/외국인 범위, 연속조회 완료 여부도 저장한다.

`PTJ04030100` (시장별 시간동향/분별)은 공식 매뉴얼 228쪽에서 입력이 시장/업종
두 개뿐이다. 이것만으로 22일 외국인 현물·선물을 소급할 수 있다고 가정하지 않는다.

공식 매뉴얼:
https://new.real.download.dws.co.kr/download/expert_manual.pdf

## 예스트레이더 대안

공식 답변은 6101 전략실행차트의 종목 선택 → 참조에서 과거 날짜의 주체별 시간
추이를 볼 수 있다고 설명한다. 답변은 2014년 자료이므로 현재 제공 종목과 보관 범위는
로그인 후 확인이 필요하다.

https://www.yesstock.com/community/qna-type2-dtl?postNo=208837

Print 함수의 CSV 추출 기능:
https://help.yesstock.com/262d121b-e719-80a4-bf77-e18718a3857f

목표 컬럼: 거래일, 시각(KST), 코스피 외국인 현물 순매수 대금,
코스피200 외국인 선물 순매수 계약, 전체 비차익 순매수 대금,
외국인 비차익 순매수 대금(제공되는 경우만), 단위, 출처, 누적/증분 구분.

분봉 시가/종가의 시각 정의와 수급의 집계 시각을 확인하고, 없는 항목은 null로 둔다.
CSV의 0을 결측으로 바꾸거나 결측을 0으로 채우지 않는다. 당일 관측이 아니라
사후 취득 자료임을 별도로 기록한다.
