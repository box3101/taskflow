# 주도주 돌파 후 눌림 v1

기존 점화 신호와 독립적인 전향적 모의 전략. 기존 122종목에 57종목을 더한 179종목을 사용하며 시장 전체 대장주를 보장하지 않는다. Railway의 기존 10초 수집과 DB 일별 JSON 저장을 공유한다. 주문·Telegram·AI 호출은 하지 않는다.

## 관찰 목록 확대 (2026-09-30 적용 예정)

기존 점화와 대장주 필터의 122종목 비교군은 그대로 유지한다. 새 전략만 `leader-strategy-additions.json`을 합친 179종목을 사용한다. 원래 종목의 탈락/진입 조건은 변경하지 않는다. 신규 57종목 모두 2026-09-29 시세 API에서 코드, 현행 이름, 거래대금 원값과 거래 가능 상태를 확인했다. 확인 시점은 장 마감 이후이므로 내일 장중 유동성이나 데이터 연속성을 보장하지 않는다. 전체 확인 결과는 `leader-universe-audit-2026-09-29.json`에 남겼다.

- 로봇 5개 추가: 기존 2개에서 7개로 확대.
- 바이오 10개: 신약·플랫폼 5개 / 의약품·생산 5개.
- 조선 10개: 조선사 5개 / 기자재 5개.
- 화장품 9개: 브랜드·유통 5개 / ODM 4개.
- 엔터 4개, 게임 5개, 인터넷 플랫폼 4개, 기업 IT·소프트웨어 4개.
- 반도체 설계 3개, 배터리 셀 1개, 유틸리티 2개 보완.

목록은 사업과 시장 테마의 연관성을 고려한 관찰 비교군이지 동일한 사업모델이나 수익률 상관관계가 입증된 묶음은 아니다. 예를 들어 SK이노베이션은 배터리 자회사 외 사업도 있고 바이오 개별 임상·기술이전 이벤트는 종목마다 다르다. 종목 수를 맞추기 위한 임의 편입은 하지 않아 엔터/ODM 등은 4개, 셀/유틸리티는 3개다. 3개 비교군의 상위 3위 조건은 선별력이 없고 거래대금 증가·상대 강도·눌림 조건으로 추가 판정한다. 차세대 전지 소재는 기존 2개로 유지하며 최소 3개 조건에 따라 진입 대상에서 제외한다.

조회되지 않은 더존비즈온(012510)은 편입하지 않았다. NC·한컴은 공급자가 반환한 현재 이름을 사용했다. 기존 종목은 이번 확대에서 제거하지 않아 전향적 비교의 기준을 보존한다. 일별 `strategyPool`, `strategyUniverseVersion`을 저장하고 실제 수집은 원본/기존 필터/새 전략 목록의 합집합을 50종목씩 나누어 수행한다. 신규 데이터 결측 시 해당 비교군은 판단하지 않는다.

## 고정 연구 규칙

- KST 09:10 이상 10:00 미만에만 신규 진입, 종목당 하루 한 번.
- 비교 종목 3개 이상인 세부 테마의 누적 거래대금 상위 3위(동순위 포함).
- 당일 등락률 양수, 테마 5분 수익률 중앙값 양수.
- 최근 5분 거래대금 / 직전 5분 거래대금 >= 1.2, 종목 5분 수익률 - 테마 중앙값 >= 0.1%p. 이는 과거 동시간대 상대 거래량과 다르다.
- 직전 5분 관측 가격 고점 돌파 후, 돌파 이후 고점에서 0.3% 이상 하락을 기다린다.
- 이후 돌파 가격 회복 및 눌림 저점 대비 0.3% 반등 확인. 모든 단계에서 후보 조건을 다시 확인한다. 조건 상실 또는 10분 경과 시 후보 초기화.
- 신호 확인 시점에는 진입하지 않는다. 다음 새로운 시세에서 돌파 가격 이상이고 진입가/눌림 저점 기준 위험폭 0.3~2%일 때 모의 진입한다.
- 눌림 저점 손절, 진입가 + 2×(진입가-저점) 목표, 최대 30분 보유. 실제 관측 청산 가격을 적용하며 목표/손절 가격의 체결을 보장하지 않는다.
- 왕복 0.21% 비용을 일괄 차감한다. 실제 세금·수수료 및 호가/슬리피지를 재현하지 않는다.
- 20초 초과 지연 시세는 사용하지 않는다. 보유 중 30초 초과 수집/시세 공백은 평가 제외. 누락된 가격 경로를 채우거나 과거 신호를 소급 생성하지 않는다.

## 저장과 해석

`spike_cloud_days.payload.leaderStrategy`에 후보, 진입 시점 비교 지표, 손절·목표, 모의 청산을 함께 영속화한다. 트랜잭션/서버 잠금은 기존 수집기와 공유하므로 재시작과 복수 인스턴스에서도 같은 일별 상태를 이어간다. API의 `strategy` 필드는 기존 점화 통계와 분리된다. 수집 중단으로 남은 미청산 기록은 조회 시에도 평가 제외 처리한다.

수익률은 거래별 동일 가중 평균이며 계좌 수익률이 아니다. 동시 보유 한도·자금 배분·주문 체결은 모델링하지 않는다. 관측 가격만 사용하므로 10초 사이의 고점·저점은 알 수 없다. 숫자는 초기 연구 가정이며 수익성 검증 결과가 아니다. 규칙 변경 시 버전을 분리하고 이후 기간에서 비용 차감 성적과 손실을 비교해야 한다.
