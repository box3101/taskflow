디자인 섹션 3: ispark-ui 컴포넌트 매핑

대시보드 각 영역에서 사용할 ispark-ui 컴포넌트와 아이콘

컴포넌트 사용 계획

📊 StatCard.vue
아이콘 <UiIcon name="folder" /> (프로젝트)
<UiIcon name="circle-check" /> (할일)
기타 순수 HTML/CSS (숫자, 라벨)
✅ TodoQuickList.vue
체크박스 <UiCheckbox /> — 완료 토글
D-day 뱃지 <UiBadge variant="danger">D-1</UiBadge>
<UiBadge variant="warning">D-3</UiBadge>
빠른 추가 <UiInput placeholder="할일 빠른 추가..." />
추가 버튼 <UiIcon name="plus" /> — 헤더 "추가" 링크
로딩 <UiLoading overlay />
📁 ProjectSummary.vue
상태 뱃지 <UiBadge variant="success">진행중</UiBadge>
<UiBadge variant="warning">보류</UiBadge>
<UiBadge variant="info">완료</UiBadge>
아이콘 <UiIcon name="users" /> (멤버)
<UiIcon name="circle-dot" /> (이슈)
<UiIcon name="arrow-right" /> (전체보기)
빈 상태 <UiEmpty /> — 프로젝트 없을 때
🏠 DashboardHome.vue (전체)
전체 로딩 <UiLoading overlay /> — 초기 데이터 로딩
토스트 openToast() — 할일 추가/완료 시
확인 다이얼로그 사용 안 함 (대시보드에서 삭제 없음)
